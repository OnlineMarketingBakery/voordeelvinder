# 0002 — Node 24 LTS instead of Node 22

- **Date:** 2026-09-29
- **Status:** Accepted (Tanjil, 2026-09-29)
- **Brief:** §4.1 says Node 22 LTS.

## Context

- Node 22 has been in Maintenance LTS since 2025-10-21 and reaches end of life on
  2027-04-30, a few months after launch.
- Node 24 is LTS until 2028-04-30.
- On Ploi, Node is installed once for the whole server (NodeSource). sites-prod-02 already
  runs v24.20.0, and no other Node app runs on that server.

## Decision

Node 24:

- `.nvmrc` is `24`;
- `engines.node` is `>=24.16.0`, the minimum for `eslint-plugin-astro`;
- CI reads `.nvmrc`;
- `@types/node` is `^24`.

## Consequences

- No server change is needed.
- Plan the move to Node 26 LTS before April 2028.
